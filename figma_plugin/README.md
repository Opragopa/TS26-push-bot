# TS26 карточки для Figma

Плагин читает TSV-лист `content_plan_cards` из AE-ready Google Sheet и создаёт или обновляет визитки в открытом Figma-файле.

## Подготовка шаблона

На текущей странице Figma создайте один шаблон и назовите его `TS26/VIZITKA_TEMPLATE`. Внутри назовите текстовые слои:

- `FIO` - имя и фамилия;
- `POSITION` - должность;
- `PHOTO` - прямоугольник или эллипс под фотографию.

Плагин умеет работать с компонентом или обычным Frame. Для компонента создаётся Instance. На повторном запуске карточка с тем же `person_id` обновляется на месте.

## Запуск

1. В Figma откройте `Plugins` -> `Development` -> `Import plugin from manifest...`.
2. Выберите `figma_plugin/manifest.json`.
3. В Telegram запустите `/ae_sync`, затем `/ae_link` и откройте AE-ready таблицу.
4. Откройте лист `content_plan_cards` и скопируйте обычную ссылку из адресной строки. Плагин сам преобразует её в TSV-export.
5. В плагине нажмите «Проверить актуальные данные». Повторное нажатие заново читает таблицу и пишет, изменились ли данные с прошлой проверки.
6. Исправьте проблемные строки в исходной таблице, снова запустите `/ae_sync`, затем заново нажмите «Проверить актуальные данные».
7. После ручной проверки нажмите «Создать / обновить».

Для теста можно вставить TSV прямо в поле плагина. Должны присутствовать колонки `person_id`, `ФИО спикера`, `Должность`, `Фото на плашку`.

## Правила

Плагин предупреждает о неполном ФИО, пустой должности, нумерации вроде `2)` и слишком длинной должности. В должностях короткие русские предлоги получают неразрывный пробел, чтобы не оставаться в конце строки. Решение о публикации остаётся ручным.

Фото из URL загружается только если источник разрешён в `manifest.json` и ссылка доступна из Figma. Если фото не загрузилось, карточка создаётся с предупреждением для ручной проверки.
